# vmware-learning-ro
Documentație tehnică în limba română pentru învățarea VMware ESXi, vSphere, vSAN, NSX și VCF.

## VMware Study LMS

Platformă personală de studiu VMware (Nivel 0 → VCP-VVF / VCP-VCF), rulează local, fără backend.

```
npm install
npm run dev
```

Deschide http://localhost:5173. Progresul se salvează în browser; fă backup din „Setări & backup”.
Convențiile proiectului sunt în `CLAUDE.md`; starea verificată a certificărilor și a labului în `docs/STATE_OF_THE_ART.md`.
